# ChatGPT 翻译器 v4.0 - 实时翻译 + 图片识别版

## 🎉 安装成功！

应用已安装并启动: `/Applications/ChatGPTTranslator.app`

## ✨ 全新功能

### 1. 实时翻译 ⚡️
- **输入即翻译** - 无需点击翻译按钮
- **自动延迟** - 停止输入 0.8 秒后自动翻译
- **流畅体验** - 像网易有道一样的实时翻译

### 2. 图片识别 📷
- **OCR 文字识别** - 使用 Apple Vision 框架
- **高精度识别** - 支持中文、英文、日文、韩文等
- **即时翻译** - 识别后自动翻译

### 3. 多种输入方式 📥
- **直接输入** - 在左侧文本框输入文字
- **复制粘贴** - 按 `Cmd+V` 粘贴图片
- **选择文件** - 点击"选择图片"按钮上传
- **多行支持** - 支持长文本和多行文本

## 🚀 使用方法

### 文字翻译
1. 在左侧输入框输入文字
2. 停止输入后 0.8 秒自动翻译
3. 翻译结果实时显示在右侧
4. 点击"复制"按钮复制结果

### 图片翻译

#### 方法 1: 粘贴图片
1. 在其他应用中复制图片(截图、网页图片等)
2. 在左侧输入框按 `Cmd+V` 粘贴
3. 自动识别图片中的文字
4. 自动翻译识别的文字

#### 方法 2: 选择图片文件
1. 点击左侧的"选择图片"按钮
2. 选择电脑中的图片文件
3. 自动识别并翻译

#### 方法 3: 截图直接粘贴
1. 按 `Cmd+Shift+4` 截图
2. 在应用中按 `Cmd+V` 粘贴
3. 自动识别并翻译

## 🔧 技术细节

### 翻译服务
- **API**: Google Translate 非官方 API
- **端点**: `https://translate.googleapis.com/translate_a/single`
- **特点**: 免费、快速、质量高

### 图片识别
- **框架**: Apple Vision
- **引擎**: VNRecognizeTextRequest
- **特点**: 离线、快速、准确
- **支持**: 中英日韩等多语言

### 实时翻译
- **防抖延迟**: 0.8 秒
- **取消机制**: 自动取消未完成的请求
- **异步处理**: 不阻塞 UI

## ⚠️ 注意事项

### 网络要求
- 文字翻译需要网络连接
- 图片识别完全离线,不需要网络
- 建议网络稳定时使用

### 使用限制
- Google 可能限制过于频繁的请求
- 建议合理使用,避免短时间大量翻译
- 正常使用完全没问题

### 图片要求
- 支持格式: PNG, JPEG, TIFF
- 建议图片清晰,文字清楚
- 太小或模糊的文字可能识别不准

### 隐私安全
- 文字翻译会发送到 Google 服务器
- 图片识别在本地完成,不上传
- 应用不存储任何内容
- 不收集用户数据

## ❓ 常见问题

**Q: 为什么输入后没有立即翻译？**
A: 为了避免频繁请求,设置了 0.8 秒的延迟。停止输入后会自动翻译。

**Q: 图片识别准确吗？**
A: 使用 Apple Vision 框架,识别准确度很高。建议使用清晰的图片。

**Q: 支持手写文字吗？**
A: 支持,但印刷体识别效果最好。

**Q: 可以离线使用吗？**
A: 图片识别可以离线,但文字翻译需要网络。

**Q: 为什么有时翻译会失败？**
A: 可能是网络问题或 Google 暂时限制。稍后重试即可。

**Q: 能否一次翻译多张图片？**
A: 当前版本每次只能处理一张图片。

**Q: 翻译结果会保存吗？**
A: 不会。应用不存储任何翻译内容,保护隐私。
