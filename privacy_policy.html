CD翻译 隐私政策

最后更新日期：2026年1月16日

简要说明：

CD翻译非常重视您的隐私。我们不会收集、存储或分享您的个人信息。图片识别在您的设备上本地完成，翻译文本仅在翻译时临时发送到第三方服务。

1. 引言

欢迎使用 CD翻译（以下简称"本应用"）。本隐私政策解释了我们如何处理您在使用本应用时的信息。

使用本应用即表示您同意本隐私政策。如果您不同意本政策的任何部分，请不要使用本应用。

2. 我们收集的信息

2.1 我们不收集的信息

本应用不会收集以下信息：

  • 个人身份信息（姓名、邮箱、电话等）
  • 位置信息
  • 设备标识符
  • 使用统计数据
  • 崩溃报告
  • 任何形式的用户数据

2.2 临时处理的信息

在提供翻译服务时，以下信息会被临时处理：

  • 翻译文本：您输入的文本会发送到 Google Translate API 进行翻译，翻译完成后不会被存储
  • 图片内容：使用 Apple Vision 框架在您的设备上本地识别，不会上传到任何服务器

3. 信息的使用

3.1 图片识别

当您粘贴图片进行文字识别时：

  • 图片使用 Apple 的 Vision 框架在您的设备上本地处理
  • 图片不会上传到任何服务器
  • 识别完成后，图片数据不会被保存

3.2 文本翻译

当您进行文本翻译时：

  • 文本会发送到 Google Translate API 进行翻译
  • 这是翻译功能正常工作所必需的
  • 本应用不会存储您的翻译内容
  • Google 的隐私政策请参考：https://policies.google.com/privacy

4. 数据存储

本应用不会在您的设备或我们的服务器上存储任何以下数据：

  • 翻译历史记录
  • 输入的文本内容
  • 上传的图片
  • 识别的文字内容
  • 应用使用记录

本应用仅在本地存储以下偏好设置：

  • 最后选择的语言
  • 窗口大小和位置

5. 第三方服务

5.1 Google Translate API

本应用使用 Google Translate API 提供翻译服务。当您使用翻译功能时：

  • 您的文本会发送到 Google 的服务器进行翻译
  • Google 可能会根据其隐私政策处理这些数据
  • 我们建议您查阅 Google 的隐私政策了解详情

5.2 Apple Vision 框架

图片文字识别使用 Apple 的 Vision 框架：

  • 所有处理都在您的设备上本地完成
  • 图片不会发送到 Apple 或任何其他服务器
  • 这是 macOS 系统自带的功能

6. 数据安全

我们采取以下措施保护您的数据安全：

  • 使用 HTTPS 加密传输数据
  • 不存储任何敏感信息
  • 图片识别完全在本地完成
  • 遵循 Apple 的安全最佳实践

7. 儿童隐私

本应用适合所有年龄段的用户使用。由于我们不收集任何个人信息，因此没有儿童隐私的特殊考虑。

8. 您的权利

由于本应用不收集或存储您的个人信息，因此：

  • 没有需要删除的数据
  • 没有需要导出的数据
  • 没有需要更正的数据

您随时可以卸载应用，不会有任何数据残留。

9. 隐私政策的变更

我们可能会不时更新本隐私政策。更新后的政策将在此页面发布，并在应用中通知用户。

继续使用本应用即表示您接受更新后的隐私政策。
