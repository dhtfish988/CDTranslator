CDTranslator Privacy Policy

Last updated: January 16, 2026

Brief description:

CDTranslator takes your privacy very seriously. We do not collect, store or share your personal information. Image recognition is done locally on your device, and the translated text is only temporarily sent to a third-party service as it is being translated.

1. Introduction

Welcome to use CDTranslator (hereinafter referred to as "this application"). This privacy policy explains how we process your information when you use this app.

By using this application, you agree to this privacy policy. If you disagree with any part of this policy, please do not use this application.

2. Information we collect

2.1 Information we do not collect

This applicationNocollects the following information:

  • Personally identifiable information (name, email, phone number, etc.)
  • Location information
  • Device identifier
  • Usage statistics
  • Crash report
  • User data in any form

2.2 Information temporarily processed

When providing translation services, the following information will be temporarily processed:

  • Translated text:The text you enter will be sent to Google Translate API for translation, and will not be stored after the translation is completed.
  • Picture content:Recognized locally on your device using the Apple Vision framework and not uploaded to any server

3. Use of information

3.1 Image recognition

When you paste an image for text recognition:

  • Images are processed natively on your device using Apple’s Vision framework
  • PicturesNoUpload to any server
  • After the recognition is completed, the image data will not be saved

3.2 Text Translation

When you translate text:

  • Text is sent to Google Translate API for translation
  • This is required for the translation feature to work properly
  • This app will not store your translations
  • For Google’s privacy policy, please refer to:https://policies.google.com/privacy

4. Data storage

This applicationNoStore any of the following data on your device or our servers:

  • Translation History
  • Input text content
  • Uploaded pictures
  • Recognized text content
  • Application usage records

This application only stores the following preferences locally:

  • Last language selected
  • Window size and position

5. Third-party services

5.1 Google Translate API

This application uses the Google Translate API to provide translation services. When you use the translation feature:

  • Your text is sent to Google's servers for translation
  • Google may process this data in accordance with its privacy policy
  • We recommend that you review Google’s privacy policy for more information

5.2 Apple Vision framework

Image text recognition using Apple’s Vision framework:

  • All processing is done locally on your device
  • Pictures are not sent to Apple or any other server
  • This is a function that comes with the macOS system

6. Data Security

We take the following measures to protect your data security:

  • Use HTTPS to encrypt data transmission
  • Does not store any sensitive information
  • Image recognition is completely done locally
  • Follow Apple's security best practices

7. Children’s Privacy

This application is suitable for users of all ages. Since we do not collect any personal information, there are no special considerations for children's privacy.

8. Your Rights

Since this app does not collect or store your personal information:

  • No data needs to be deleted
  • No data needs to be exported
  • No data needs correction

You can uninstall the app at any time without leaving any data behind.

We may update this privacy policy from time to time. The updated policy will be posted on this page and users will be notified in the app.

By continuing to use this app, you accept the updated privacy policy.
