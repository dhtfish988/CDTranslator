# ChatGPT Translator - Instructions for Use

## ✅ Installation completed

The application was successfully installed and launched: `/Applications/ChatGPTTranslator.app`

## 🚀 Quick Start

### 1. Text translation (real-time)

**Direct input, automatic translation**

```
1. Enter text in the left input box
2. Stop input 0.8 Automatic translation after seconds
3. Translation results are displayed on the right in real time
4. click"Copy"Button to copy results
```

**Features:**
- ✅ No need to click the translate button
- ✅ Translation as you type, smooth experience
- ✅ Supports multi-line long text
- ✅ Automatic debounce to avoid frequent requests

### 2. Image translation (copy and paste)

**Screenshot and Translate**

```
1. Press Cmd+Shift+4 Screenshot (or screenshot in any way)
2. Press in the left area of the translator Cmd+V Paste
3. Automatically recognize text in pictures
4. Automatically translate recognized text
```

**Copy image and translate**

```
1. On the web page/Right-click to copy the image in the document
2. Press in the left area of the translator Cmd+V Paste
3. Automatically recognize and translate
```

**Features:**
- ✅ Just Cmd+V, no need to select files
- ✅ Supports direct pasting of screenshots
- ✅ Supports copying and pasting pictures
- ✅ Automatically recognize and translate

## ❓ Frequently Asked Questions

**Q: Why is it not translated immediately after typing? **
A: In order to avoid frequent requests, a delay of 0.8 seconds is set. It will be automatically translated after you stop typing.

**Q: How to paste pictures? **
A: After copying any picture, press Cmd+V in the left input area.

**Q: Can I paste the screenshot? **
A: Yes! After taking the screenshot, just press Cmd+V to paste it.

**Q: Is the picture recognition accurate? **
A: Using the Apple Vision framework, the recognition accuracy is very high. It is recommended to use clear pictures.

**Q: Does image recognition require an Internet connection? **
A: No need! Image recognition is completely done locally, but translation requires a network.

**Q: Does it support handwritten text? **
A: Supported, but the print recognition effect is the best.

**Q: Can I paste multiple pictures at one time? **
A: The current version processes one image at a time.

**Q: How to switch back to text input after pasting a picture? **
A: Just click the "Clear" button in the upper right corner.

**Q: Will the translated content be saved? **
A: No. The application does not store any content and protects privacy.
