CDTranslator — draft listing copy

This is source-repository copy, not evidence of an App Store release or approval.

CDTranslator is a macOS window app for translating text as you type. Press Cmd+V
with an image on the clipboard to recognize its text using Apple Vision, then
translate the recognized text online.

The current translation path chooses its own direction: mainly Chinese to English
and Latin-letter input to Simplified Chinese, with language detection for other
input. The language menus do not currently provide arbitrary language-pair control.

OCR runs locally. Text, including OCR results, is sent to Google for translation.
The current build has no background clipboard monitoring and does not enable App
Sandbox. Translation uses an undocumented endpoint and may become unavailable.

Requirements: Apple silicon, macOS 13 or later, internet access for translation.
