CDTranslator Privacy Policy

Last updated: January 21, 2026

Overview

CDTranslator (hereinafter referred to as "this application") attaches great importance to user privacy protection. This privacy policy explains how this application collects, uses and protects your information.

Information collection

This application does not collect, store or transmit any of your personal information. Specifically:

  • Translate text: The translated text you enter will be processed through a third-party translation service (Google Translate), and this application will not store these texts.
  • Image recognition: Image text recognition is completely performed on the local device, using the Vision framework that comes with the macOS system, and the image data will not be uploaded to any server.
  • Clipboard data: This application may read images in the clipboard for text recognition, but will not store or transmit the clipboard content.

Third-party services

This application uses the following third-party services for translation:

  • Google Translate: Translation requests are sent to Google servers. See Google Privacy PolicyLearn more.

Data Security

This application uses the following measures to protect your data:

  • All network requests are transmitted encrypted using HTTPS
  • Image recognition is completely performed locally and no image data is uploaded
  • This application runs in a macOS sandbox environment, which limits access to system resources.

User Rights

Since this app does not collect or store any personal data, there is no user data that needs to be deleted or exported.

Children’s Privacy

This application is not specifically targeted at children under the age of 13, nor does it knowingly collect personal information from children.

Privacy Policy Update

We may update this privacy policy from time to time. The updated policy will be posted on this page and the "Last updated date" will be updated.

Contact us

If you have any questions about this privacy policy, please contact us by:

Email: support@cdtranslate.app

CD Translate Privacy Policy

Last Updated: January 21, 2026

Overview

CD Translate ("the App") takes user privacy very seriously. This Privacy Policy explains how the App collects, uses, and protects your information.

Information Collection

The App does not collect, store, or transmit any personal information. Specifically:

  • Translation Text: Text you enter for translation is processed through third-party translation services (Google Translate). The App does not store this text.
  • Image Recognition: Image text recognition is performed entirely on your local device using macOS's built-in Vision framework. Image data is never uploaded to any server.
  • Clipboard Data: The App may read images from your clipboard for text recognition but does not store or transmit clipboard contents.

Third-Party Services

The App uses the following third-party services for translation:

  • Google Translate: Translation requests are sent to Google servers. Please refer to Google's Privacy Policy for more information.

Data Security

The App employs the following measures to protect your data:

  • All network requests use HTTPS encryption
  • Image recognition is performed locally without uploading any image data
  • The App runs in the macOS sandbox environment, limiting access to system resources

User Rights

Since the App does not collect or store any personal data, there is no user data to delete or export.

Children's Privacy

The App is not specifically targeted at children under 13 and does not knowingly collect personal information from children.

Policy Updates

We may update this Privacy Policy from time to time. Updated policies will be posted on this page with an updated "Last Updated" date.
