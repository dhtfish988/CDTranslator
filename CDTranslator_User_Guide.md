```

2. Press in the app Cmd+V
3. Automatically recognize and translate
```

## ✨ Features

### 🌟 real-time translation
- Translate as you type, no need to click a button
- Intelligent debounce, smooth experience
- supports multi-line long text

### 📷 Image recognition
- Copy any picture
- Press Cmd+V to paste
- Automatic text recognition
- Automatic translation results

### 🎯 Simple and easy to use
- No configuration required

## ❓ Frequently Asked Questions

**Q: How to paste pictures? **
A: After copying any picture, just press Cmd+V anywhere in the application.

**Q: What image formats are supported? **
A: PNG, JPEG, TIFF and other common formats.

**Q: Is the picture recognition accurate? **
A: Using the Apple Vision framework, the recognition accuracy is very high.

**Q: Do you need internet? **
A: Image recognition is offline, and text translation requires an Internet connection.

**Q: Is it completely free? **
A: Yes! No configuration required, completely free to use.

**Q: Is the translation speed fast? **
A: Very fast! Use the Google Translate API for fast response times.

**Q: Will my translations be saved? **
A: No! The app does not store any data, fully protecting privacy.
