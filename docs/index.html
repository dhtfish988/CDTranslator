CDTranslator Privacy Policy

Updated September 22, 2026

This page describes the current build from the CDTranslator source repository. Older experimental backends in the repository may behave differently.

Text sent for translation

Typing or pasting text starts an automatic translation request. The app sends that text to Google at translate.googleapis.com over HTTPS, with the text in the request's URL query. If the text contains personal information, that information is sent too. Google also receives connection information such as your IP address. No account or API key is required by this app.

Images and the clipboard

Pressing Cmd+V with an image on the clipboard reads that image and runs Apple Vision OCR locally on your Mac. The app does not upload the image through this path. It does send the recognized text to Google for translation. The current build does not continuously monitor the clipboard.

Storage and third parties

The current source does not implement saved translation history or app-specific analytics. Text and images are held while the app processes or displays them. This is not a promise that the operating system, network stack or Google keeps no caches or records. Google's processing and retention are governed by its privacy policy, not by this project.

Translation uses an undocumented Google endpoint. Its availability and behaviour may change. Avoid entering confidential information you do not want to send to Google.

Build permissions

The current documented build does not enable macOS App Sandbox. A source entitlements file is present but is not applied by that build command. Local OCR does not imply that the app is sandboxed or that text translation is offline.

Choices and contact

To avoid sending text, do not enter it or paste an image for translation. There is no offline-only translation mode in the current app.

For questions or corrections, open a GitHub issue. Do not include private text, screenshots or credentials in a public report. Changes to this page will update the date above.
